# Hello World C Project

This repository contains my first C programming project set up with VS Code and Git.

## File Overview
* `hello.c`: A basic C program that prints "Hello, World!".

## How to Run
1. Open terminal in VS Code.
2. Compile using GCC: `gcc hello.c -o hello`
3. Execute the binary: `.\hello.exe`
